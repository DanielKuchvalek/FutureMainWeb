# Utopia Corp. – prezentační web

Jednostránkový web pro návrh a vývoj webů, e-shopů a aplikací. Představuje služby, postup spolupráce a hotové projekty (proball.cz, Lynqo, LIONS Handball, handballturnaje.cz, Handball Camp, Meandrie).

## Co web umí
- **Animovaný úvod v Canvasu** – pixely se rozletí a poskládají nápis UTOPIA, myš je odhání
- **Animace při rolování** – postupné odkrývání bloků a obrázků, plovoucí pixely
- **Vlastní kurzor** a interaktivní prvky
- **Přístupnost** – respektuje `prefers-reduced-motion` (omezí animace)
- **Kontaktní formulář v PHP** – validace, limit odeslání z jedné IP, ukládání zpráv mimo veřejnou část webu, volitelně odeslání e-mailem
- Vlastní písma na serveru, bez externích knihoven

## Technologie
- HTML5, CSS3
- Vanilla JavaScript (ES moduly, Canvas API, IntersectionObserver)
- PHP (kontaktní formulář)
- Apache (`.htaccess`)
